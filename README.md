# SENVA 深维 — Own the Edge.

A speculative luxury brand website for a graduate design project: **SENVA**, a fictional Shenzhen house
for ultra-luxury personal intelligence instruments, and its flagship **SENVA V1**. Everything here
(brand, founders, product, people, atelier, data) is invented. There is no backend.

## Open it

No install needed. Double-click **`index.html`** (any modern browser). Fonts load from Google Fonts when online and
fall back to system fonts offline.

## What is inside (single file: `index.html`)

SENVA is an ultra-exclusive **ambient AI ecosystem**, not a smartwatch brand. The wearable is one interface of three.

- Custom loader and geometric wordmark; cinematic hero: **One intelligence. Everywhere you are.** (residence, wearable and
  vehicle, joined by one thread of light)
- The Advantage of Ownership, Visionary / Strategist / Pioneer identities
- **The Ecosystem**: Home / Wear / Drive tabs, a permission-based "one identity" diagram you can switch on and off,
  and a day-in-the-life sequence. *Always present. Never intrusive.*
- **The Human Concierge**: *Intelligence with a human behind it.* 24/7 advisor, responsibilities and interactive example requests
- **Redefining Luxury**: *AI provides intelligence. Humans provide accountability. Luxury provides privilege.*
- SENVA Wear (secondary): simulated multi-angle viewer with hotspots (CORE, Materials, Interaction, Intelligence, Security)
- The Four Dimensions (scroll-driven), a conceptual private-intelligence demonstration, four people stories, the Atelier
- **Three environments, one intelligence**: commission builder (include Home / Wear / Drive, choose the Wear finish)
- The House, a six-stage commissioning journey, and a private-access form (client-side validation, demo-only submission)
- Responsive, keyboard accessible, `prefers-reduced-motion` supported

## Notes

- Imagery, interiors and the wearable are generated vector art, not photography or a 3D model.
- The brief named React/Next.js/Tailwind/Framer Motion/Three.js; this build is deliberately dependency-free
  vanilla HTML/CSS/JS so it runs with no installation.
- Product details are design intent only. No certified specifications, endorsements, facilities or
